
# NumberSystemConverter

A menu-driven C++ program for converting numbers between
binary, decimal, octal, and hexadecimal systems.

## Features

- Binary to decimal
- Decimal to binary
- Decimal to octal
- Decimal to hexadecimal
- Octal to decimal
- Hexadecimal to decimal
- Basic input validation

## Technologies Used

- C++
- Loops and conditional statements
- Strings
- Number system arithmetic

## How to Run

Compile:

    g++ main.cpp -o converter

Run on Windows:

    converter.exe

Run on Linux or macOS:

    ./converter

## Example

Binary input: 1010

Output: Decimal: 10

## Learning Outcomes

This project demonstrates number system conversion,
string processing, loops, and arithmetic operations.

## Limitations

The program is intended for non-negative integer inputs
within the supported range of the C++ long long type.
